# IC Markets — referencia de sesiones (complemento al scan)

Fuente: [IC Markets Trading Hours](https://www.icmarkets.sc/global/en/trading-pricing/trading-hours)  
Server time del broker: **GMT+2** (invierno) / **GMT+3** (DST).  
Argentina (ART): **UTC−3**. En invierno server≈UTC+2 → ART = server−5h; en DST server≈UTC+3 → ART = server−6h.

> Las ventanas del informe de scan están en **UTC / ART** derivadas del PnL simulado, no del horario contractual. Este archivo es el marco operativo del broker.
